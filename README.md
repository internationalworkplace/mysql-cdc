# MySQL CDC (Change Data Capture) Binlog Parser

This repository contains a MySQL binlog parser for Change Data Capture (CDC).

## Overview

The MySQL CDC Binlog Parser is a tool that allows you to extract and parse the binary log files (binlogs) generated by MySQL. It provides a way to capture and process the changes happening in a MySQL database in real-time.

## Features

- Connects to a MySQL database and reads the binary log files.
- Parses the binlog events to extract information about the changes made to the database.
- Supports various event types, such as INSERT, UPDATE, DELETE, and ALTER TABLE.
- Provides a flexible API for processing the captured changes.
- Supports filtering and transformation of the captured data.
- Can be integrated with other systems or applications for further processing or analysis.

## Getting Started

To get started with the MySQL CDC Binlog Parser, follow these steps:

1. Clone the repository: `git clone https://github.com/your-username/mysql-cdc.git`
2. Build the project: `cargo run`
3. Run the binlog parser: `target/debug/mysql-cdc data/bin.000001`
   
## Building for Windows

1. Requirements

```
brew install openssl
brew install cmake
brew install gcc
brew install mingw-w64
```

2. Environment variables

```
export OPENSSL_ROOT_DIR=/opt/homebrew/Cellar/openssl@3/3.3.0
export OPENSSL_INCLUDE_DIR=/opt/homebrew/Cellar/openssl@3/3.3.0/include
export OPENSSL_LIB_DIR=/opt/homebrew/Cellar/openssl@3/3.3.0/lib

export LDFLAGS="-L/opt/homebrew/Cellar/openssl@3/3.3.0/lib"
export CPPFLAGS="-I/opt/homebrew/Cellar/openssl@3/3.3.0/include"
export PKG_CONFIG_PATH="/opt/homebrew/Cellar/openssl@3/3.3.0/lib/pkgconfig"
```

3. Compiling

```
cargo build --target x86_64-pc-windows-gnu --release
```

## Usage

Once the binlog parser is running, it will start capturing the changes happening in the MySQL database. You can use the provided API to process and handle these changes according to your requirements. Refer to the documentation for more details on how to use the API.
